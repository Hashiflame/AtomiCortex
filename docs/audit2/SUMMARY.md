тренер, — ни одна метрика ни к какой модели не привязана. Модель обучена предсказывать одно
событие (верхний барьер 1.5·ATR раньше нижнего 1.0·ATR), исполнение реализует другое (стоп
1.5·ATR, TP считается и на биржу не уходит). Вся торговая история — восемь сделок — переигровка
реконсилятором по несуществующему TP-ордеру; на ней построены `daily_stats`, API и весь Telegram.
В live 14 признаков из 46 расходятся с обучающими, 11 порядково, и с 2026-08-14 прод-бот
структурно не может записать ни строки в `signals_log`. Бот в `--dry-run`: риск-дефекты не
реализуются, снятие флага обнажит их разом.
